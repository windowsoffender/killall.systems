Every callout type the theme ships with. Delete this post whenever.

{{< note >}}
A plain note, the default. Just a heads up with no fuss.
{{< /note >}}

{{< info >}}
Some **info** with a bit of `inline code` and a [link](/) inside. The body is
normal markdown so anything works.
{{< /info >}}

{{< tip >}}
A handy tip. Use these to point out a shortcut or a nicer way to do something.
{{< /tip >}}

{{< warning >}}
A warning. Pay attention or something mildly bad happens.
{{< /warning >}}

{{< danger >}}
Danger. This is the loud one for when something will really break.
{{< /danger >}}

You can also override the label:

{{< danger "do not" >}}
Pass a title in quotes and it replaces the default one.
{{< /danger >}}
